Build Professional PDF Report Generation for ReadyLoq.

Goal:
Transform completed inspections into customer-facing PDF reports that can be downloaded, emailed, printed, and attached to customer records.

Requirements:

REPORT COVER PAGE

* ReadyLoq logo
* Company logo (white-label support)
* Company name
* Property name
* Property address
* Inspection date
* Technician name
* Inspection type
* Report number

EXECUTIVE SUMMARY

* Overall inspection summary
* Risk level (Low / Medium / High)
* Total findings
* Total recommendations
* Areas inspected
* Follow-up required (Yes/No)

FINDINGS SECTION

For each finding include:

* Finding title
* Severity
* Location
* Description
* Supporting evidence photos
* AI confidence score (if applicable)

Display findings in professional card format.

PHOTO EVIDENCE SECTION

* Full photo gallery
* Caption for each photo
* Date captured
* Location tag
* Ability to include multiple photos per finding

RECOMMENDATIONS SECTION

For each recommendation:

* Recommendation title
* Priority
* Related finding
* Recommended corrective action
* Estimated urgency

PROPERTY INTELLIGENCE SECTION

Include:

* Recurring issues
* Historical hotspots
* Previous activity locations
* Known conducive conditions

Show this as historical property knowledge.

SERVICE HISTORY SECTION

Include:

* Previous visits
* Historical findings
* Last technician
* Callback history

MANAGEMENT INSIGHTS SECTION (optional)

* Property risk trend
* Callback indicators
* Repeat issue indicators

BRANDING

Must support:

* Company logo
* Company colors
* Company contact information
* Company tagline

PDF FEATURES

* Professional print layout
* Letter size
* Mobile friendly
* Download button
* Generate PDF button
* Preview before download

TECHNICAL

Use react-pdf or equivalent production-ready solution.

PDF generation must work from real inspection data already stored in the database.

All photos, findings, recommendations, technician notes, and Property Intelligence data should populate automatically.

Output should resemble a professional inspection report suitable for direct customer delivery.
