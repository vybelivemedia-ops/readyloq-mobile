PHASE 1 — PRODUCTION OAUTH

* YouTube (Google OAuth 2.0)
* Facebook Pages (Meta OAuth)
* Instagram Professional Accounts (Meta OAuth)
* Twitch OAuth 2.0

* Use official OAuth flows only.
* Never request or store user passwords.
* Store access tokens and refresh tokens server-side only.
* Encrypt all tokens at rest.
* Support automatic token refresh.
* Detect expired tokens.
* Notify creators when reauthorization is required.
* Support connect, disconnect, reconnect, and account switching.
* Persist all platform connections in the database.
* Display connected account name, profile image, and status.
* Display permission errors clearly.
* Validate livestream permissions after connection.
