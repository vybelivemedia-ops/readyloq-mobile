Implement production-ready AI clipping, highlight detection, caption generation, content management, and social reposting for VYBE LIVE.

GOAL

After a livestream ends, creators should automatically receive AI-generated clips that can be reviewed, edited, and reposted to supported platforms from within VYBE LIVE.

PHASE 1 — CLIP PIPELINE

Create a clip generation service.

Requirements:

* Process completed livestream recordings.
* Support portrait (9:16) clip generation.
* Support Shorts, Reels, and TikTok formats.
* Create clips of configurable length:
    * 15 seconds
    * 30 seconds
    * 60 seconds
* Generate multiple clips per stream.
* Store clips in creator library.

Database:

* clips
* clip_jobs
* clip_assets

Store:

* clipId
* streamId
* userId
* startTime
* endTime
* duration
* thumbnailUrl
* videoUrl
* status
* createdAt

PHASE 2 — AI HIGHLIGHT DETECTION

Create highlight detection engine.

Detect:

* Viewer spikes
* Chat spikes
* Reactions
* Loudness peaks
* Keyword triggers
* Manual creator markers

Generate highlight candidates automatically.

Store:

* highlight score
* confidence
* timestamp

PHASE 3 — TRANSCRIPTION + CAPTIONS

Generate transcripts automatically.

Requirements:

* Speech-to-text
* Word timestamps
* Caption generation
* Burned-in captions
* Editable captions

Support:

* English initially
* Multi-language ready architecture

PHASE 4 — AI TITLES + HASHTAGS

Generate:

* Clip title
* Description
* Hashtags
* Platform-specific captions

Outputs:

* TikTok caption
* YouTube Shorts title
* Instagram caption
* Facebook Reel caption

Allow creator editing before publishing.

PHASE 5 — CREATOR CLIP LIBRARY

Create Clips screen.

Features:

* View clips
* Search clips
* Delete clips
* Download clips
* Share clips
* Publish clips

Filters:

* Recent
* Best performing
* Unpublished
* Published

PHASE 6 — SOCIAL PUBLISHING

Support publishing workflow.

Platforms:

* YouTube Shorts
* Facebook Reels
* Instagram Reels

Use OAuth connections already implemented.

Requirements:

* Publish immediately
* Schedule publishing
* Retry failed publishing
* Store publish status

Database:

* content_posts

Store:

* platform
* clipId
* status
* publishedAt
* failureReason

PHASE 7 — BACKGROUND JOBS

Create workers:

* clipProcessor
* transcriptionWorker
* captionWorker
* publishingWorker

Requirements:

* Queue processing
* Retry handling
* Failure logging
* Progress tracking

PHASE 8 — ANALYTICS

Track:

* Clip views
* Published clips
* Top performing clips
* Generated clips
* Engagement

Display in creator dashboard.

PHASE 9 — REMOVE MOCK IMPLEMENTATIONS

Replace all placeholder clip generation.

Replace all simulated publishing.

Replace all demo clip data.

PHASE 10 — VALIDATION

After a creator finishes a livestream:

1. Recording saved.
2. AI detects highlights.
3. Clips generated automatically.
4. Captions generated.
5. Titles generated.
6. Clips appear in library.
7. Creator can publish to connected platforms.

SUCCESS CRITERIA

A creator can:

* Finish a stream.
* Receive AI-generated clips automatically.
* Review clips.
* Publish clips to connected platforms.
* Manage all content from VYBE LIVE.
