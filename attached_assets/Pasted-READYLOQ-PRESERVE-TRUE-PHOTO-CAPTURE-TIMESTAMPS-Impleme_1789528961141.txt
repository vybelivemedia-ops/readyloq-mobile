READYLOQ — PRESERVE TRUE PHOTO CAPTURE TIMESTAMPS

Implement ONLY this targeted fix.

The read-only timestamp audit confirmed:

- Mobile already creates the authoritative EvidenceItem.capturedAt / LocalPhoto.capturedAt timestamp at capture time.
- That timestamp is currently not sent during media registration.
- The server therefore creates inspection_media.created_at at registration time.
- The Company Portal currently maps media.createdAt into a property named capturedAt.
- This is incorrect for delayed/offline uploads.

GOAL:

Preserve the actual device capture instant separately from server registration time.

IMPLEMENT:

1. DATABASE

Add a nullable:

inspection_media.captured_at

Use the existing timestamp conventions in the project.

Do NOT remove or repurpose created_at.

created_at must continue to mean server media-row creation/registration time.

2. API

Update the inspection media registration contract to accept:

capturedAt

Validate it as a valid timestamp.

Persist it to inspection_media.captured_at.

Do not overwrite captured_at with server time.

3. MOBILE

When registering media, send the existing:

LocalPhoto.capturedAt

Do not create a new timestamp for this purpose.

Do not change camera capture behavior.

Do not change Evidence Pipeline architecture.

Do not change offline persistence.

4. PORTAL API

Expose both values where appropriate:

capturedAt
createdAt

Semantics must be explicit:

capturedAt = actual device/evidence capture instant
createdAt = server media registration/audit timestamp

5. COMPANY PORTAL

When displaying evidence capture time:

prefer:

capturedAt

fallback to:

createdAt

This fallback is required for historical media created before captured_at existed.

Do NOT rewrite historical created_at values.

6. CROSS-MIDNIGHT DISPLAY

Review the existing media timestamp display.

When evidence spans multiple calendar dates, make the displayed date understandable.

Do not blindly change every media tile to a larger UI.
